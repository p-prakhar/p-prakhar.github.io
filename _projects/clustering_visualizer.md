The desktop application loads CSV, Excel, and MATLAB datasets and runs
K-Means, DBSCAN, or Affinity Propagation across configurable parameter ranges.
It can create synthetic datasets for experiments and applies PCA when the
source data has more dimensions than can be plotted directly.

Results can be explored as 2D or 3D plots. For iterative algorithms, the tool
also renders the changing clusters as a slideshow or video, making convergence
and poor parameter choices easier to see than they are in a final static plot.

[Browse the source](https://github.com/p-prakhar/clustering-visualizer).
